# Snakes

A single-file snake game. Play it at https://j3k0.github.io/snakes/

The whole game is one `index.html` — no build step, no dependencies, no accounts.
The only network request the game makes is to a free, anonymous, cookie-less
counter (page loads, per-day loads, games started/finished, and a few
first-visit steps — which step of the funnel a player reached). No accounts,
no analytics platform, no fingerprinting, no personal data, no cookies.
